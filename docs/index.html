stage-drop

Staging site tĩnh tức thì, mang đi được: kéo-thả zip → nhận URL tạm → claim trước khi hết hạn.

Lấy cảm hứng từ Cloudflare Drop MIT TypeScript + Hono Workers · R2 · KV
Trang này chỉ là docs tĩnh (GitHub Pages). API upload/claim chạy trên lab Worker — không chạy trên Pages. Thử demo live hoặc clone repo và npm run dev.

Cách hoạt động

Upload

Thả zip (≤10 MB, ≤500 file) có index.html. Nhận live + claim URL.

Live URL

Site phục vụ dưới /s/:siteId/ trong 60 phút nếu chưa claim.

Claim

Token một lần (≥128-bit). Chỉ lưu hash; claim xóa hạn + xoay hash.

Sweep

Cron */5 dọn site hết hạn chưa claim khỏi R2 + KV.

Kiến trúc

Core Hono portable sau interface BlobStore / MetaStore. Lab Worker: R2 (sites/{id}/) + KV (meta:, claim:, exp:). Local: FS + in-memory. Pages = intro tĩnh; Lab = API thật.

meta:{id}

SiteMeta JSON (claimed, expiresAt, claimTokenHash…).

claim:{sha256}

Tra token → siteId (chỉ lưu hash).

exp:{expiresAt}:{id}

Chỉ mục phụ cho sweepExpired.

Luồng request (lab)

Upload → validate → R2 + KV → liveUrl/claimUrl; serve /s/:id; claim; cron sweep.

flowchart TD
  U["Upload zip"] --> V["Unzip + validate"]
  V --> R2["R2 sites/{id}/"]
  V --> KV["KV meta:{id} · claim:{sha256} · exp:{expiresAt}:{id}"]
  KV --> URL["liveUrl + claimUrl"]
  S["GET /s/:id"] --> M["Lookup meta"]
  M -->|ok| SR["Serve from R2"]
  M -->|unclaimed expired| G["410 Gone"]
  C["Claim token"] --> H["SHA-256 → claim:{hash}"]
  H --> CL["claimed=true · expiresAt=null · delete exp: · rotate claim hash"]
  CR["Cron */5"] --> SW["sweepExpired"]
  SW --> DEL["Delete R2 + all KV keys"]

Máy trạng thái site

LiveUnclaimed → Claimed (one-shot) hoặc Expired (TTL 60 phút) → sweep xóa.

stateDiagram-v2
  [*] --> LiveUnclaimed: upload
  LiveUnclaimed --> Claimed: claim one-shot
  LiveUnclaimed --> Expired: TTL 60 min
  Expired --> [*]: cron sweep
  Claimed --> [*]

Claim (one-shot)

Hash lookup → claimed=true, expiresAt=null, xóa exp:, xoay claim hash (token cũ vô hiệu).

flowchart LR
  T["Raw claim token"] --> H["SHA-256"]
  H --> L["KV claim:{hash} → siteId"]
  L --> U["Update meta: claimed · expiresAt=null"]
  U --> D["Delete exp: key"]
  U --> R["Rotate claim hash — one-shot"]

Bắt đầu nhanh

Demo live trên lab Worker, hoặc chạy local — GitHub Pages chỉ host trang docs tĩnh này.

# clone & install
git clone https://github.com/vovanduc/stage-drop.git
cd stage-drop
npm install

# verify + start local
npm test          # should be green
npm run dev       # http://localhost:8787
