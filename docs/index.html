stage-drop

Portable instant static-site staging: drag-and-drop a zip → get a temporary live URL → claim it before it expires.

Inspired by Cloudflare Drop MIT TypeScript + Hono
This page is static docs. The live upload/claim API runs locally (or later on Workers) — not on GitHub Pages. Clone the repo and run npm run dev to try the real server.

How it works

Upload

Drop a zip (≤10 MB, ≤500 files) with index.html. Get live + claim URLs back.

Live URL

Site is served under /s/:siteId/ for 60 minutes unless claimed.

Claim

One-shot token (≥128-bit). Only a hash is stored; claim clears expiry.

Sweep

Periodic cleanup removes expired unclaimed sites from blob + meta stores.

Architecture

Core Hono app behind portable BlobStore and MetaStore interfaces. Local FS + in-memory today; R2/KV and S3/DynamoDB are future adapters.

Quickstart

Run the real server locally — GitHub Pages only hosts this static companion site.

# clone & install
git clone https://github.com/vovanduc/stage-drop.git
cd stage-drop
npm install

# verify + start
npm test          # should be green
npm run dev       # http://localhost:8787

# then open the UI, drop a zip, live URL under /s/:siteId/
