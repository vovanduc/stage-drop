stage-drop

Staging site tĩnh tức thì, mang đi được: kéo-thả zip → nhận URL tạm → claim trước khi hết hạn.

Lấy cảm hứng từ Cloudflare Drop MIT TypeScript + Hono
Trang này chỉ là docs tĩnh. API upload/claim chạy local (hoặc sau này trên Workers) — không chạy trên GitHub Pages. Clone repo và chạy npm run dev để thử server thật.

Cách hoạt động

Upload

Thả zip (≤10 MB, ≤500 file) có index.html. Nhận live + claim URL.

Live URL

Site phục vụ dưới /s/:siteId/ trong 60 phút nếu chưa claim.

Claim

Token một lần (≥128-bit). Chỉ lưu hash; claim xóa hạn.

Sweep

Dọn định kỳ các site hết hạn chưa claim khỏi blob + meta store.

Kiến trúc

App Hono lõi đứng sau interface BlobStore và MetaStore mang đi được. Hiện tại: FS local + in-memory; R2/KV và S3/DynamoDB là adapter sau. Biểu đồ: Mermaid (+ SVG dự phòng).

Kiến trúc

Bắt đầu nhanh

Chạy server thật trên máy — GitHub Pages chỉ host trang docs tĩnh này.

# clone & install
git clone https://github.com/vovanduc/stage-drop.git
cd stage-drop
npm install

# verify + start
npm test          # should be green
npm run dev       # http://localhost:8787

# then open the UI, drop a zip, live URL under /s/:siteId/

Ảnh chụp

Luồng demo local: upload → live URL → claim. Ảnh load từ shot-*.js.
